Joy Project Design System

The visual language for the Barbie Movie Marathon and Charity Match site — scrapbook warmth, editorial structure, built to feel like a memory rather than a marketing campaign. Use this page as the source of truth while building screens.

🩷 Derived from the approved build spec · applies to Home, Events, Get Involved, and the ticket flow

Color

One warm ground, one ink, four accents. Pink belongs to the movie marathon, green to the match — never swap them.

Before you ship it

Two lenses — does it still feel like the Joy Project, and does it still feel handmade rather than generated.

Audience & tone

  • Boys visibly present in the Barbie experience
  • Girls visibly present in the football match
  • No section reads as a donation ask
  • Feels like a university event, not an NGO campaign

Anti-AI check

  • Every section perfectly symmetrical? Add asymmetry.
  • Every element decorated? Remove some.
  • Handwritten font everywhere? Reduce it.
  • Photos look like stock? Replace with candid shots.

Accessibility

  • Visible focus states on every interactive element
  • Alt text on all meaningful images
  • Handwritten type never used for essential info
  • prefers-reduced-motion respected
